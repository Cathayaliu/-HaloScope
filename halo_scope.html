这是什么

晕景 HaloScope 是一个冰晕模拟器——把真实天空中出现的太阳光环、彩虹光弧 搬进你的电脑。它用物理光线追迹: 让成百上千万条阳光射入云中的六角冰晶, 按斯涅尔定律折射、全反射, 投到天球上, 就形成了 22° 晕、幻日、环天顶弧等 大气光学现象。
调好参数 → 点右上角「✓ 确认并渲染」 → 在左侧画布看到结果。

快速上手

1. 在「渲染图片」页点一个预设(如“环天顶弧”), 参数自动填好;
2. 想改太阳就拖画布上的太阳光点(或填数字), 想看相机实拍就切“拍摄视图”;
3. 点「✓ 确认并渲染」, 等几秒~几十秒看到结果;
4. 想要视频: 切「导出视频」, 设好扫描范围, 点「▶ 开始渲染动画」。

术语小抄

天球视图: 把整个天空压成一张圆图——圆心=头顶正上方, 外圈=地平线。 光弧离太阳多少角度直接读半径, 一眼看懂这是什么晕。
拍摄视图: 像站在地面用相机拍天空, 有地平线(以下为黑), 更接近实拍照片。
方位角: 太阳/相机在水平面上的朝向(0°=北, 顺时针)。
高度角: 太阳离地平线多高(0°=贴地平线, 90°=头顶)。
σ(取向散布): 冰晶飘得“整齐”还是“乱”。σ 越小弧越细越锐, 越大越宽越淡。

每个调整项的作用

【预设】一键填好典型参数, 新手直接用。

【太阳方位角】太阳朝哪边; 0°=画面正上方, 顺时针转。
【太阳高度角】最关键的一个值——不同太阳高度会照亮不同的冰晕: 22° 晕任何高度都有; 环天顶弧要太阳 20~30°; 幻日/环地平弧要太阳低(约 0~40°)。
【天球视图 / 拍摄视图】两种看天的方式(见术语小抄)。
【相机方位角 / 仰角 / FOV】(仅拍摄视图) 相机朝哪、抬多高、广角多大。 FOV 越大看得越广, 但东西越小。

【随机柱晶】六棱铅笔冰晶, 朝哪个方向的都有 → 画出完整的 22°/46° 圆晕。
【取向柱晶】铅笔冰晶“横着飘”(长轴贴地) → 幻日旁的上侧弧、切弧。
【取向片晶】六角薄片“平着飘”(大面朝上) → 幻日、头顶的环天顶弧、 地平线上的环地平弧。
【随机锥晶】两端带 6 面金字塔尖的六角柱, 姿态完全随机 → 9°/18°/20°/23°/ 24°/35° 一大圈锥晶圆晕(太阳低时在 22° 晕内侧出现一组小晕)。
【取向锥晶】锥晶“横着飘”(长轴水平) → 锥晶幻日、锥晶上侧弧。 真实云中常与随机锥晶并存, 比例影响圆晕与幻日谁更亮。
【柱晶长宽比 / 片晶厚径比】冰晶的胖瘦。默认柱晶 1.0(等轴柱)、片晶 0.15(典型薄片), 改它们会改变哪条弧更亮。
【锥角(半角)】锥尖的倾斜角度。真实云最常见 28°(给出整组 9°–35° 圆晕); 调小则各锥晶晕半径变小、调大变圆(用“锥晶圆晕”预设可快速对比)。
【柱晶取向 σ / 片晶取向 σ / 锥晶取向 σ】“整齐度”。0°=绝对整齐(弧极细), 越大弧越宽越淡, 真实云大约 2~5°。

【色散强度】彩虹程度: 0=白光晕, 1=浓浓的红橙绿青蓝(黄昏感)。
【视野(天顶距)】光圈范围: 140° 能同时看全 22°+46°+环地平弧; 调小可放大局部。
【并行线程】计算用几个 CPU 线程(0=自动)。
【光线数(M)】画质/速度开关: 越大越平滑细腻, 但更慢。4M 平衡, 16M 精细, 64M 壁纸级(适合配 2:3/9:16 画幅做桌面, 单次渲染需数分钟)。
【亮度】整体明暗。弧太暗调大, 太大太阳会过曝。
【平滑 σ】柔化程度: 太小有颗粒/断点, 太大弧发虚; 0.9 是甜点值。
【网格 / 方位线 / 外圈】参考线开关, 帮你看弧离太阳多少度, 不需要就关。
【物理模式】关闭追迹层的能量修正(驻点增益·多次 TIR 衰减), 成像与色彩照常 — 用于观察"未放大"的真实相对亮度: 环天顶/环地平弧会明显变暗, 其余弧相对增强。

【画幅比例】(右上角按钮组, 图片/视频通用) 1:1 正方形; 16:9 / 3:2 / 4:3 横向; 2:3 / 9:16 竖向(手机竖屏风格)。 3:2 像照片, 16:9 像视频。
【起始/结束高度角、步长】视频里让太阳从低升到高(或反过来), 步长越小帧越多越流畅。
【每帧光线数】视频每帧的画质(同“光线数”)。
【帧率(fps)】每秒多少帧: 15 够看, 30 更流畅。

小技巧

画布上的太阳光点可以直接拖动, 不用敲数字;
拍摄视图下拖动画面旋转相机;
改“镜头运动”参数后, 动画正在渲染时不切换设置——先停止动画再改。

原理(选读)

光线入射到六角冰晶(按投影面积随机选面), 在晶体内逐面折射/全反射后出射; 以 5 个波长(红→橙→绿→青→蓝)分别追迹并按 Fresnel 透射率加权, 叠加出真实色散; 天空用瑞利+米氏单次散射近似, 所以太阳附近亮、对面暗。 全离线运行, 无网络请求。
